# Project Instructions

This repository is a clean starting point for a client website. Keep it generic and reusable.

## Boundaries

- Shared components and UI configuration come from @mwheeler91/ui.
- Shared API behavior, contracts, logging, and utilities come from @mwheeler91/site-core.
- Client branding, routes, page templates, content, and demos belong in the client repository.
- Do not add client-specific names, URLs, assets, or credentials to this scaffold.
- Runtime API values belong in environment variables and use the VITE_ prefix.

## Validation

Run npm run type-check, npm run build, and npm run test:unit before handing off changes.
